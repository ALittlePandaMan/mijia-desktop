# 自动化编辑与录像改进

2026-11-11

自动化添加面板的取消、添加按钮使用水平及垂直居中。全屋默认不放置自动化，仍允许在长按编辑后添加任何房间的任务；列表尚未加载完成时也保留入口，已打开的面板随加载结果更新。普通房间的首次布局展示所有云端关联的手动任务，不受常用标记或数量限制；后续新增任务自动加入默认入口，明确隐藏的项目继续隐藏。

排列顶栏覆盖在客户端标题栏下方，移除页面下移 44px 的处理。设备和自动化长按均保持家庭及房间导航位置，保留原有卡片、拖动指针及取消恢复流程。

录像直接封装收到的原始码流。Opus 和纯视频录像保存为 MP4，PCM 与 G.711 音轨随视频保存在 MOV 中。独立 FIFO 写入线程的队列上限为 512 包和 8 MiB。磁盘跟不上时，录制结束并保存已写入的完整片段。结束录制时先排空队列，再按选择的截止时间生成文件。编码参数发生变化时，结束当前录制并保留先前有效片段。

录像跳过只有编码参数或分隔符的包，保留视频的可变帧间隔和有效时间缺口。重复和倒退时间戳使用有效步长，轨道时长和样本索引共用同一组时序。PCM 和 G.711 音轨按各自的原始采样率和实际样本数建立索引。

验证：1201 项前端测试、617 项 Rust 测试、63 项隔离完整页面检查、类型和源码检查通过。录像测试覆盖写入线程被阻塞时先接收 300 帧、队列过载显式失败、音视频交错、编码异常和停止时排空/裁剪。修改前本机短样片含 306 帧、15.28 秒，约 20.03fps；这次没有复现持续降低帧率。以上改进消除客户端写盘阻塞及索引异常风险，无法恢复摄像头本身或链路已经没有传来的帧。最终客户端交付和本机短录验证见 `.tools/scene-edit-record-delivery.json` 与 `.tools/scene-edit-record-native-results.json`。

本机全屋检查还定位到回位动画结束前点击添加会被拖动保护忽略。增加 `DeviceDrag.settleLanding()`：指针松开后可以立即完成回位并打开选择面板，仍按住拖动时保留保护。额外模拟 2.5 秒回位动画的设备和自动化入口测试均通过，用户不必等待动画结束或再次点击。

最终签名客户端已交付并正常重启，12 项本机检查通过，包含全屋添加草稿、取消恢复、不挤占内容的设备/自动化长按、添加文字双轴居中及摄像头短录。最终样片视频轨道 343 帧 / 17.142 秒，约 20.009fps；音视频样本计数和时长索引一致。测试未保存用户排列或执行自动化，调试端口已关闭。
