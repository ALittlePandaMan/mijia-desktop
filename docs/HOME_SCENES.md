# 家庭场景

首页在“全屋”之前提供“场景”标签。照明和遮阳按米家房间排序，使用可换行网格；没有相应设备的房间不会出现。照明包含 MIoT 灯、灯组及可控制的有线开关，不把插座或摄像头电源计入灯光。设备显隐设置及无线模式过滤继续生效。

房间及全屋按钮分别发送明确的开、关、打开、暂停、关闭意图，复用既有 home-card 的规格校验、权限检查、属性写入与回读。点击后在当前事件内更新全部目标的本地意图，复用设备卡片的同一队列，不再整组禁用或等待回读；离线、只读及不可操作设备不发送。切换家庭后未发送的队列停止。无法确认的写入不会自动重发。

环境区仅展示温湿度计，使用现有设备属性和近 24 小时云端历史接口。温度、湿度分别展示独立曲线卡片，宽窗口并排、窄窗口上下排列，不显示左侧摘要或指标切换。首次进入读取数据，此后每个整点读取一次；切换房间和设备列表轮询不重复读取。历史与读数整批更新，临时读取失败保留上次成功的数据；曲线按整点与半点分成 30 分钟区间，区间内有效读数取平均并保留一位小数；空缺区间保留断线，不补零、不插值。图表实例跨设备控制及首页轮询保留，仅容器尺寸实际变化时调整，离开页面时释放实例和观察器。湿度属性使用 MIoT 的 `relative-humidity`，蓝牙设备读取不可用时复用 `propertyReading` 的 `lastReported`。

## 米家任务

房间标签下、设备卡片上方展示已有的一键任务。全屋和场景页默认不显示自动化入口；具体房间默认展示米家账号返回的全部 `common_used_roomIds` / `room_id` 关联的一键执行任务，不按常用标记筛选、不限制默认数量；仅用户显式添加跨房间入口后显示其他房间任务，用户手动隐藏的入口保持隐藏。按钮宽度与下方设备卡片完全相同，复用设备网格计算后的列轨道及间距（包括小数像素），窗口缩放时同步更新；不再使用半宽至整宽的范围计算。高度 48、图标 24、左右留白 12、上下留白 4、图文间距 6，横纵条目间距随下方设备网格同步（默认 12）。名称最多两行，超出省略。点击执行不显示“执行中”“已发送”等文字。

长按设备卡片或自动化入口进入共用整理模式，自动化右侧出现勾选标记；自动化可拖动排序，不显示批量移除按钮。顶部完成保存设备及自动化的布局，取消恢复原状。“添加自动化”仅在长按进入排列模式后显示，提供当前家庭的其他房间任务及已隐藏入口，支持多选；右键菜单可隐藏当前房间的入口。全屋整理模式也可显式添加入口，但初始为空。

上述添加、移除和隐藏仅改变桌面入口，不编辑或删除米家云端任务。配置随账号、区域、家庭、房间分别保存，使用本地 `sceneShortcuts`，并保留原有设备顺序及显隐设置。执行、排序、移除及添加是分开的交互，编辑不会触发任务执行。

入口整理更新已验证：46 项相关前端测试、10 项本地设置 Rust 测试、20 项模拟完整页面交互检查、12 项真实客户端只读检查通过。覆盖默认隐藏、双行截断、任务点击无状态文字、拖动、保存、取消恢复、移除、跨房间添加、恢复隐藏入口、右键菜单、窄窗口与原有设备拖动。真实客户端检查未保存任何布局变化、未执行任务，模拟测试中的点击仅调用测试传输。

- 读取：`/appgateway/miot/appsceneservice/AppSceneService/GetSceneList`，数字 `home_id`。
- 手动触发判据：`scene_trigger.triggers` 存在 `src=user` 且 `key=user.click`，`enable=true`，且记录属于当前家庭。`type` 无法区分条件自动化和手动任务。
- 执行：`/appgateway/miot/appsceneservice/AppSceneService/NewRunScene`，固定 `scene_type=2`、`trigger_key=user.click`，携带当前家庭及所有者。
- 每次执行前重新读取并校验手动任务白名单，检查家庭、代次和账号身份；请求标识在发送前消耗，重复标识不再发送。
- 不自动重试场景执行，也不展示发送状态文字；登录失效仍使用原有登录处理。

仅增加读取、执行两个 Tauri 命令，没有创建、编辑、删除或开关条件自动化的入口，也没有向 MCP 增加新的写入工具。
