# 平台支持与安装

当前仅发布 Windows x64。Linux 和 macOS 的安装包、CI 编译及平台验收暂缓；源码中的已有适配保留，尚不作为受支持的发行版。

| 平台 | 架构 | 格式 | 凭据存储 |
| --- | --- | --- | --- |
| Windows 10/11 | x64 | NSIS 安装程序、便携 ZIP | 当前用户凭据管理器 |

## 安装与运行

Windows 需要 WebView2 Runtime，安装程序按 Tauri 的引导方式处理。便携版应完整解压，保留许可和文档。首版未提供商业代码签名，请从本项目 Releases 下载并核对校验值。

## 数据与媒体

Windows 数据目录保持 `%LOCALAPPDATA%/io.mijiadesktop.client`，会话使用当前用户凭据管理器，不回退到明文文件。更新程序时保留现有用户配置。

默认保存到系统“视频”目录下的“米家Desktop”，不存在标准视频目录时使用用户主目录下的 `Videos`。程序创建“截图”和“录制”，使用本地时间戳文件名。已有自定义路径继续使用；旧媒体文件不会因为默认值变化自动搬迁或删除。恢复默认使用新的视频目录规则。

## 支持边界

- 登录、设备页面和云端控制共用 Rust 逻辑；具体能力仍由设备和服务返回值决定。
- 摄像机视频、Opus 音频和对讲受系统 MediaSource、WebCodecs 和麦克风权限支持限制，编译成功不表示所有型号的音视频都可用。
- 监控进入／退出保存窗口大小和位置。

本轮仅静态审查、编译和包文件检查，没有运行自动化测试、实机界面验收、开麦、观看摄像头、保存新媒体或控制设备。Windows 安装、登录保持、目录窗口、监控几何、媒体解码和系统权限的实际行为均待验收。Linux/macOS 的构建发布及实际交互留待后续处理。
