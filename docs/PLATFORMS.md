# 平台支持与数据

## 支持平台

正式版提供 Windows 10/11 x64 的 NSIS 安装程序和便携 ZIP。Linux 和 macOS 的源码适配仍在进行。

运行需要 WebView2 Runtime。安装程序检测缺失或低于 111.0.1661.34 的运行时，按需联网引导安装或更新。便携版需完整解压。电脑无法联网时，可先由管理员或当前用户安装微软的 WebView2 Evergreen x64 独立安装程序。[微软离线安装说明](https://learn.microsoft.com/microsoft-edge/webview2/concepts/distribution#offline-deployment)

Windows Authenticode 商业代码签名尚未配置。应用内更新使用独立的 Tauri/Minisign 签名并校验版本。

## 账号与数据

Windows 用户数据目录为 `%LOCALAPPDATA%/io.mijiadesktop.client`。账号、各业务会话、助手令牌及 MCP 密钥由系统凭据库或后端的系统保护存储管理，不回退为公开明文文件。

更新不清空账号、MCP 设置、家庭勾选、设备偏好或桌面布局。截图和录像默认保存到系统“视频/米家Desktop”目录；没有标准视频目录时使用用户目录下的 `Videos`。可在设置中更改位置，既有路径继续有效，更新不搬迁或删除媒体。

## 功能边界

- 设备能力取决于型号、固件、账号权限和服务响应；设备在线不代表所有功能均可用。
- 摄像机事件与录像日期使用 UTC+8，与后台查询一致；电脑处于其他时区也保持同一日期边界。
- 客户端随包提供 FFmpeg 兼容解码组件，覆盖授权会话的 H.264、HEVC 和支持的音轨。系统播放优先，软件兜底需要支持共享缓冲的 WebView2。摄像机和对讲能力还取决于型号及权限。客户端无需 Go 或 Java 运行时。[视频播放与兼容解码](VIDEO_PLAYBACK.md)
- 监控的全屋范围独立于 MCP 家庭选择。切换监控范围不自动建立视频连接。
- 桌面卡片默认每屏关闭；屏幕关闭或断开时保留记录。跨屏仅允许已开启的屏幕，四边留白作用于工作区。
- MCP 仅提供本机 Streamable HTTP 与预配置 Bearer 认证，不提供标准 OAuth 自动发现。助手首版仅支持已验证的中国区服务组合；家庭列表参数不证明云端强隔离。
- 任务取消不能撤销已经发生的硬件动作。云端成功报告与设备实测核验分别表达，不用云端文字改写确认状态。

## 验证范围

CI 运行前端、Rust、浏览器 Mock、文档、能力及源码检查，所有自动化设备写入使用模拟传输。模拟测试不替代原生 Windows 鼠标、混合 DPI、多屏热插拔、各型号音视频和真实设备行为验收。

安装升级失败恢复、跨版本更新流程及未完成的真实设备／混合 DPI 场景不宣称已经通过。后续问题请在 [GitHub Issues](https://github.com/ALittlePandaMan/mijia-desktop/issues) 提供版本、系统和脱敏复现步骤，勿附账号令牌、密钥或家庭画面。
