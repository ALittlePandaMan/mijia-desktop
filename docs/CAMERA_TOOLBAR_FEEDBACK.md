# 摄像头工具栏、保存提示与全屏画质菜单

## 2026-11-12 存储卡回放修正

- 倍速切换使用已核实的 271（0x10f）速度指令，沿用当前 playback session，不重开录像、不重新创建 MSE，也不清空已缓冲帧。端侧提供 0.5／1／2／4 倍播放，传输沿用已验证的 1／4 档。网络不足或既有有界缓冲耗尽后的补读仍可能等待，不能宣称任何情况下都无缓冲。
- 按最新要求不实现倍速声音。SD 与看家助手在非 1 倍速时关闭声音并禁用声音按钮，切回 1 倍速后按钮恢复可用，保留静音直到用户主动开启；不增加不支持说明或提示文案。原始插件在倍速时同样主动静音；C700 只读验证中 1 倍速返回 62 个 Opus 包，4 倍速返回 0 个音频包。
- SD 与云端回放全屏均隐藏实时工具栏，仅显示对应回放工具。门铃事件筛选入口保持透明背景，菜单项的选择与键盘焦点仍可见。
- 小时封面只在相册打开时串行读取对应录像首帧，复用已暂停的 SD 会话，不开多个摄像头连接；每次只取一帧，缓存最多 72 项。切换日期、镜头、选择录像或离开页面会取消旧任务；关闭相册恢复进入前的位置、速度和暂停状态。失败封面可在下次打开重试，不能用其他时刻的画面冒充。
- 相册日期、设备事件日期及体脂秤成员生日全部复用自定义日期弹窗，无原生日期输入入口；已存在的日期范围约束继续生效。

本轮验证使用模拟回放及本机 UDP 协议测试，不实际操作家庭设备。Rust 回归 542 项、前端回归 1040 项通过；浏览器验证倍速不重建、倍速静音与声音按钮、暂停保留、全屏单工具栏、小时封面、取消恢复和自定义日期。倍速声音已按用户要求排除；真实网络下持续吞吐仍受设备与连接条件影响。

- 监控工具栏的全屏、截图、录像和麦克风使用同一套 24×24 矢量及 1.6 单位线宽，显示尺寸统一为 20px。声音开启及静音恢复此前原版素材，保持原来的造型，同样显示为 20px。麦克风开启保持相同形状，以颜色和既有活动动效表示状态；录制时显示停止图标。
- 摄像头名称标签与工具栏底边对齐，普通格子底距 8px，小格子 5px；为右侧工具栏预留空间，长名称省略，避免相互遮挡。
- 截图、实时录像和回看录像成功保存后，顶部居中显示 3.2 秒的成功 toast。只对实际返回的保存文件提示；开始录制、正在保存和失败不冒充完成。命令回复、异步事件及监控详情共享保存文件去重，最多保留 64 个文件标识。
- toast 不抢焦点，使用状态播报；现代 WebView 中采用手动 popover 顶层显示，兼容设备详情 dialog 和视频全屏，退出对应会话时清理。其他设备操作的安静反馈规则继续保留。
- 详情原先将画质菜单放在全屏视频容器外，导致菜单在全屏背后打开。现在菜单移动到实际全屏镜头内，退出后放回详情页；关闭后恢复画质按钮焦点。普通详情和两个镜头分别使用同一处理。
- 监控墙和单格全屏保留原有菜单入口，明确工具栏及画质菜单层级，避免视频或画中画覆盖菜单。

沿用用户此前“不验证”的要求，仅生产编译、交付文件一致性核对及正常启动。未运行测试、浏览器检查、实机截图、录像或画质切换。以下场景仍待验证：不同缩放下的图标视觉大小、密集小格子的标签与工具栏、普通详情和两个镜头的全屏菜单、键盘关闭及焦点恢复、监控格子全屏菜单、截图和录像的成功提示、保存失败无成功提示、重复异步事件去重、toast 在 dialog 和全屏切换时的显示、退出和家庭切换后的清理。
