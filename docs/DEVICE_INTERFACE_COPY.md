# 设备页面说明文案清理

- 用电、温湿度、净水器和管线机统计不再展示“未完整取回”“仅合计已取得记录”等附加脚注；门铃事件和设备自检记录同样不展示此类脚注。
- 移除设备设置、通用属性和动作编辑器中重复的协议、适配及回读说明。控件的禁用原因保留在辅助功能描述中。
- 数据读取、统计数值、完整性标记、查询范围、重试入口、权限校验和写入限制保持原有逻辑。
- 保留实际错误、空状态、操作所需说明、输入范围和安全确认；无可用按键、模式等空状态使用简短文案。
- 公共文案处理补充历史统计脚注类型，避免旧渲染入口再次显示该类说明。

本次仅进行生产编译、打包一致性核对和正常启动，不运行测试、浏览器检查或实体设备操作。

待验证：统计部分返回、统计读取失败与重试、空记录、记录翻页、离线或只读控件、无可用枚举或范围，以及净水器、管线机、温湿度和门铃页面布局。
