# 设备弹窗与家庭列表滚动位置

2026-11-11

从全屋列表下方打开儿童房2床头开关时，后台家庭列表会向上跳。打开过程重建家庭 DOM，设备网格先使用默认单列；原滚动位置恢复后，微任务才计算实际多列宽度。浏览器在这次列数变化中执行滚动锚定，随后异步渲染继续保存了已经偏移的位置。

在家庭 DOM 接入页面后，立即计算设备网格和自动化网格，再恢复家庭的垂直滚动位置及房间导航的水平位置。后续微任务沿用相同的布局。修复适用于共用这条渲染路径的设备页，不改变卡片宽高、间距、按压动画或云端控制逻辑。

修改前，隔离完整页面中滚动位置从 1792 变为 396；本机实际儿童房2床头开关从 1444 变为 516.67，返回后也保持了错误位置。修复后隔离检查覆盖 480、1000、1280、1920px 窗口，全屋及普通房间，有自动化的布局、慢速读取、缓存打开、键盘打开、读取失败及返回后的后台刷新；逐帧检查滚动位置保持不变，65 项检查通过。前端 1201 项测试、类型检查及源码检查通过。

最终桌面版的实际开关检查结果保存在 `.tools/home-scroll-stability-native-results.json`，构建与本地交付记录在 `.tools/home-scroll-stability-delivery.json`。验证仅打开和关闭设备页，不切换实体开关或执行自动化。
