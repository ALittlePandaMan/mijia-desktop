离线 Mock 覆盖七工具、Skill/搜索、上下文、聚合目录与共享、统一 SSO/两个SID/恢复/撤销、协议兼容、受限回退、SSE、任务防重放及目录断网查询取消。Streamable HTTP fixture 不执行真实设备指令。

运行前端类型/测试/生产构建、Rust、文档、轻量入口、小线程栈回归。浏览器模拟与原生进程/端口/崩溃/设置保留/重启分别记录。自动化不发设备命令。

独立子任务并发与关联请求透传验收：Mock 云端请求通过屏障证明两个 UUID 同时在途，检查乱序返回、部分失败和无额外设备查询；真实 Streamable HTTP 会话验证同会话并发、原 UUID 轮询和去重。分流示例覆盖整组灯、亮度、温度、同设备关联、顺序、条件和场景，验证收到的子任务文本不被后端改写或扩展。

这些离线示例指定宿主应发送的请求，不是内置 Agent，也不代表外部模型已正确分流。外部宿主重新连接、是否实际并行以及最终回复需单独记录；原生服务指引加载、离线协议测试和真实 Agent 行为不能互相替代。

新扫码、二次验证、真实刷新、共享家庭控制及硬件状态要独立受限实机证据。服务端强隔离和回退执行前拒绝未证明的项目保持未验证，不能由成功回复代替。
