# 应用内更新

“设置 → 关于”显示应用图标、名称、当前版本及程序类型，提供检查更新、更新日志和更新状态。应用与启动中不再显示软件更新，自动更新开关及定时后台检查均已删除。旧配置中的自动更新字段被忽略，保存设置时不再写入。

用户点击“检查更新”后，发现稳定版时可点击“立即更新”。之后由原生任务在后台下载，切换页面不会中断。下载通过签名校验后自动结束摄像头会话与录制、停止 MCP、静默安装并重启，无需另行点击安装。更新期间可在关于中查看进度。下载或签名失败不会重启，显示具体原因并允许重试；安装未能启动时恢复程序运行。没有用户触发时不自动检查、下载或安装，普通退出也不安装已下载的包。

安装前保存原版本、目标版本和实际更新内容。新程序仅在自身版本匹配目标版本、且确实高于原版本时显示“已更新到 v…”弹窗，包含版本变化、更新内容及完整更新日志入口。只有用户点击“知道了”或按 Esc 确认后才记录已读，之后不再显示。安装未完成、版本未变化及普通同版本本地启动不会误报更新成功。更新内容按纯文本展示，不执行远端 HTML。

更新仅连接固定 GitHub 仓库，不发送米家账号、令牌、设备或视频数据。更新清单限制为 1 MiB，下载包限制为 256 MiB，只接受匹配平台、版本、仓库附件路径和公钥签名的包。签名绑定实际版本，拒绝旧包冒充新版本；不会降级。检查请求有超时，网络失败不会自动密集重试。

Windows x64 安装版使用 NSIS quiet 模式静默更新并重启；便携版使用独立助手等待旧进程退出，再校验并替换程序文件，完成后重启。程序目录不可写时给出错误，不会将便携版迁移成安装版。账号、偏好、截图和录像的用户目录不参与替换。替换失败时回滚已修改文件。

签名密钥不随源码或便携包分发，发布流程见 [发布维护](RELEASING.md)。当前仅 Windows x64 正式程序开放应用内更新，开发运行和其他平台显示限制。

完整静默升级、安装失败恢复及跨版本结果弹窗需独立原生验收，不能用包签名或浏览器模拟代替；不为演示更新发布测试版或操作真实设备。
