# 监控名称对齐与重复画质档位

- 监控格子底部的设备名称与工具栏放在同一行，通过弹性布局垂直居中。普通格子仍保持 8px 底距，小窗口及小格子为 5px；长名称在工具栏旁省略，不再依靠预估工具栏宽度或固定高度偏移。
- 两个手动画质的型号显示“原画、流畅、自动”；三个不同手动画质的型号继续显示“原画、高清、流畅、自动”。自动仍是独立选择，没有当前实际尺寸时只显示文字。
- 型号配置或已经取得的手动档位尺寸确认“高清”和“原画”重复时，合并成一行“原画”。明确公布了不同分辨率的三档型号继续保留高清，不因过渡帧暂时相同而隐藏。没有足够信息确认重复时保留型号原有选项，不自动探测或猜测能力。
- 当前原生档位若仍为已合并的高清值，菜单中原画显示选中，工具栏也显示原画。合并只影响展示，不自动重连、切流或改写设备与画质偏好；后续手动点击继续使用原有协议档位。
- 详情、监控和全屏菜单共享判断。新尺寸到达时更新当前打开的菜单，并在条目增减时恢复选中项焦点；双镜头按各自尺寸判断。

按此前“不验证”的要求，只做生产编译、交付文件一致性核对和正常启动。未运行测试、浏览器检查或实机画质操作。待验证：不同缩放和格子大小下的居中与名称截断、两档型号、明确三档型号、重复档位的已保存选中值、尺寸未知及迟到变化、菜单打开时动态增减与焦点、双镜头和全屏。不得记为通过。
