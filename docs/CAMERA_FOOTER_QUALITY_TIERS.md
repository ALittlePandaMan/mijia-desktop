# 监控名称对齐与重复画质档位

- 监控格子底部的设备名称与工具栏放在同一行，通过弹性布局垂直居中。普通格子仍保持 8px 底距，小窗口及小格子为 5px；长名称在工具栏旁省略，不再依靠预估工具栏宽度或固定高度偏移。
- 手动画质按型号提供的档位显示“超清、高清、流畅”。设备支持“自动”时独立展示。
- 相同协议参数或相同的已确认镜头尺寸会合并，包括超清参数实际返回流畅码流的情况。菜单仅显示档位名称。画质确认后的关键帧和稳定解码尺寸用于更新观测，后台降档与历史磁盘缓存不参与去重。
- 已选原生档位继续映射到实际对应的选项。合并只改变菜单展示，保留现有会话及画质偏好。
- 详情、监控和全屏菜单共享判断。新尺寸到达时更新当前打开的菜单，并在条目增减时恢复选中项焦点；双镜头按各自尺寸判断。

离线测试覆盖两档、三档、重复低档、双镜头读值隔离、选中和焦点恢复。真实摄像头和屏幕组合单独验收。
