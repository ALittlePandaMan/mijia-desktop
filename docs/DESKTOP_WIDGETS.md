# 桌面设备卡片

## 启用与摆放

在“设置 → 桌面卡片”选择显示器并开启。每个屏幕独立控制，默认关闭；选择屏幕不会改变开关。主屏排在首位，显示器原标识和布局不变。

启用后可在设备右键菜单固定到桌面。没有启用屏幕时先前往设置开启。关闭屏幕或拔下显示器只隐藏卡片，保留设备、尺寸和位置；再次开启或连接后恢复。

设备卡片与软件主页共用显示和控制组件。点击打开现有设备详情；快捷按钮只执行自身操作。小、中、大三档尺寸由右键菜单切换，当前尺寸不重复列出；没有边框缩放手柄。

## 栅格与留白

每屏可选择 `6 × 4` 或 `8 × 6` 栅格，切换后立即保存。卡片按栅格占位，空间不足时保持现有有效配置并说明原因。

上、右、下、左四个留白输入使用逻辑像素，在系统工作区内进一步预留空间，用于避开 Dock 等覆盖内容。预览随合法草稿实时内缩，非零边缘显示测距标注；点击“应用留白”才保存，“重置留白”恢复零值。各屏草稿独立保留。

留白统一作用于栅格、卡片尺寸、吸附、交换和落点提示，不修改系统工作区。改动设置不迁移到其他账号。

## 拖动与交互

鼠标按住移动达到 4 个逻辑像素即可拖动，轻点仍打开详情。拖动显示合法落点；可交换时另一张卡片预览移动，移开后返回，松手才保存。无效落点回退，不挤动其他卡片。

仅能拖入已开启桌面卡片的屏幕，朝未开启屏幕移动时在当前屏幕边界停住。跨屏使用同一全局物理矩形，由各屏裁剪显示。混合 DPI 下保持拖动预览连续，释放后适配目标屏幕的栅格。

三档尺寸变化使用现有 300ms 动画，遵守减少动态效果设置。中大卡字号采用稳定基准，模板控件与快捷按钮不触发卡片拖动。

## 控制与资源

按钮、描述、目标数值与关联控件可用性统一使用本地显示投影。操作立即反馈，后台下发及回读；失败或首个确认读取错误静默回退，不把预测值保存为真实读数。详见 [本地优先控制](LOCAL_FIRST_CONTROLS.md)。

每个已启用屏幕复用一个透明宿主，保持固定工作区坐标系；纯移动使用 transform，不逐帧重新测量布局。空白区域穿透，桌面图标优先，普通应用覆盖时遵守桌面层级。全部屏幕关闭时释放宿主、输入代理和相关刷新任务。

布局按账号保存，保留旧格式读取和当前格式恢复；预览、动画和手势状态不持久化。升级不清空固定记录或桌面布局。

浏览器回归使用模拟宿主与设备，不等同于真实 Windows 鼠标、混合 DPI、休眠恢复和多屏热插拔验收。
