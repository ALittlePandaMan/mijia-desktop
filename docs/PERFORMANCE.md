# 资源管理与性能回归

性能基线使用上一版“每屏共享宿主”签名构建。本轮报告不得把此前从逐卡片 WebView 迁移到共享宿主的收益重复计入。

## 资源所有权

| 资源 | 创建者与共享范围 | 自动工作与释放条件 |
| --- | --- | --- |
| 账号会话、云端客户端 | 根 Rust AppState；子家庭上下文共享 Arc | 账号失效禁止访问；退出时收尾，不因界面休眠重建 |
| 型号规格、卡片配置、界面元数据 | 根仓库；UI、MCP、小组件共享 | 沿用有界缓存、请求合并和失败退避；不缓存凭据到公开元数据 |
| 设备观察值与意图队列 | 规范化端点及账号、家庭作用域 | 操作优先；旧读取不能覆盖更新的写入，界面节能不取消已接纳的控制 |
| 家庭子上下文 | 共享构造器；小组件不复制整屋面板 | 最后订阅释放后移除；库存时间只来自成功读取，不能以缓存访问时间代替 |
| 主 WebView | Tauri 主窗口 | 遮挡或隐藏时暂停非必要工作；空闲 30 秒后尝试休眠，保留 DOM、草稿与页面 |
| 桌面宿主 | 每个有卡片的显示器一个 WorkerW 子窗口 | 空宿主销毁；完全遮挡时停止渲染投递，恢复时同步最新快照 |
| 桌面输入和图标保护 | 原生输入适配服务 | 没有输入目标时移除钩子、停止图标扫描并等待唤醒；不在鼠标回调中查询 COM 或设备 |
| 报告控制器与页面计时器 | 当前设备页面 | 非必要自动读取随页面暂停；必要的发送及确认继续；闲置上下文有界回收 |
| 图表与运动动画 | 当前视图 | 隐藏时停止绘制；恢复按真实截止时间更新，不逐帧或逐秒补跑 |
| 摄像头预览与回放 | 原有会话、镜头及控制器 | 不可见的无声画面可暂停；录制、导出、对讲、有声播放及待完成控制阻止相关页面休眠 |
| 缩略图、图片、监听器 | 所属页面或卡片 | 图片源不变时保留节点；暂停不必要的预取，退出页面释放观察器、定时器和媒体引用 |

## 行为约定

- Windows 按实际窗口与卡片区域检查遮挡，不以失去焦点或全屏通知状态单独判定。透明、异形窗口以及检测失败时，保守地保留活动状态。
- 单屏全屏应用不会暂停另一屏仍可见的卡片。屏幕有卡片或需要画拖动预览时才创建宿主。最后一张卡移除后立即清空已呈现内容和输入区域，交互结束后保留五秒供复用，再释放宿主。
- 可见主页及桌面卡片约每 10 秒批量读取。通用详情约每 5 秒读取，专用详情沿用各自的节拍。隐藏区域暂停常规状态读取，首次进入、恢复可见及应用内场景触发后合并补读。
- 同一会话、家庭和物理属性的短时被动读值可供各窗口共享。操作确认使用直接读取，本地目标与确认值分别维护。米家 APK 的 MQTT／Android 推送使用宿主订阅链路，当前桌面登录尚未验证可用的推送鉴权，因此客户端使用批量补读。
- 后台状态在 Rust 保留最新值，避免休眠页面积累消息。恢复先唤醒，再恢复输入和最新快照。
- 关闭主窗口进入托盘不会无条件结束正在进行的媒体任务；托盘退出执行完整收尾。
- 不关闭硬件加速、不强制清空工作集、不定时重载或销毁主页面。系统不支持 WebView2 休眠时跳过，不影响控制。

## 可重复采样

Windows 采样需要 PowerShell 7；组件集成测试还需要 Node.js 和临时开启的本机 WebView 调试端口。正常启动不开放该端口。

只读采样无需改变应用配置：

```powershell
pwsh -NoProfile -File scripts/perf/sample-windows.ps1 -RootPid <应用进程号> -Seconds 180 -Output .cache/perf/background.json
node scripts/perf/summarize.mjs .cache/perf/background.json
```

采样只统计应用进程树。私有提交和工作集分开报告；CPU 按累计 CPU 时间与实际采样间隔换算为一个逻辑核的百分比。GPU 使用进程引擎计数器，显存共享分配不当作去重后的物理 VRAM。少于 100 个样本不输出 P95。

`scripts/perf/widget-matrix.mjs` 提供 0／1／5／10 张卡片及双屏的可见、遮挡场景。该工具只执行固定、移动和取消固定，不执行设备控制。它要求显式传入未纳入源码的私有设备清单和 `--allow-layout-changes`，并从已备份的临时空布局开始；完成后移除测试卡片。应用配置的原样备份和恢复须在应用停止时执行，检测到外部布局修改时停止覆盖。

```powershell
node scripts/perf/widget-matrix.mjs --fixture .cache/perf/private-devices.json --exe <测试可执行文件> --pid <应用进程号> --out .cache/perf/matrix.json --seconds 30 --allow-layout-changes
```

`scripts/perf/run-widget-matrix.ps1 -Executable <exe> -Fixture <私有清单> -Output <报告路径> -AllowLayoutChanges` 封装正常退出、私有布局备份、临时空布局、测试及原样恢复；可用 `-Modes covered` 单独复测遮挡场景。它拒绝覆盖测试后仍有卡片或出现外部修改的布局。私有备份包含设备身份，应留在未提交的本机缓存目录。

设备清单形状为 `{ "devices": [{ "homeId": "…", "did": "…" }] }`，不得提交或打包。集成测试通过应用自己的 IPC 校验账号与设备绑定，不能传任意设备路由绕过授权。

浏览器回归在独立测试浏览器中执行，不接入真实设备；媒体生命周期使用模拟会话，卡片控制记录 100 次乐观更新到下一动画帧的时间：

```powershell
node scripts/perf/check-widget-browser.mjs .cache/perf/widget-browser.json
node scripts/perf/check-lifecycle-browser.mjs 9444 http://127.0.0.1:1421 .cache/perf/media-lifecycle.json
node --test scripts/widget-boundary.test.mjs
```

这两项浏览器检查需要先在 1421 启动测试用 Vite，以及使用独立临时用户目录、9444 调试端口的浏览器。卡片检查中的调试鼠标事件仅作用于该浏览器页面，不模拟系统桌面输入。

`scripts/perf/cover-windows.ps1` 创建独立的不透明测试窗口，支持指定屏幕和部分遮挡；不修改分辨率、桌面或系统设置。这只能验证遮挡与无边框全屏窗口行为，不能代替真实游戏、独占全屏或第三方桌面兼容性测试。

## 验收与解释

- 前后版本使用同一 WebView2、设备、图片、尺寸、屏幕布局和缓存条件；正常启动与调试测量分开记录。
- 同屏 1–10 张卡片的宿主数始终为 1，双屏最多为 2；取消固定后没有遗留宿主或重复读取。
- 检查 180 秒网络观察、100 次模拟控制反馈、五轮草稿保留唤醒、20 轮宿主及休眠生命周期和 30 分钟后台观察。
- 前台内存中位数或启动耗时回退超过 5% 必须调查。后台 CPU、GPU、提交内存、工作集、JS 堆及句柄各自报告，不用其中一项代替另一项。
- 实物测试先落盘原值，完成后核对恢复。云端回读匹配不是目视或硬件新鲜度证明。
- Windows 10、真实游戏、Explorer 重建、锁屏、显示器热插拔和其他平台的结果逐项注明，未实测的场景不标记通过。
