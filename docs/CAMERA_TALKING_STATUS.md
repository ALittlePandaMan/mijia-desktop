# 摄像头通话状态提示

- 通话成功建立后，在对应摄像头画面右上角显示绿色“正在通话”标记。申请麦克风权限、等待摄像头确认、取消或失败时均不显示成功状态。
- 监控墙、单格全屏、普通设备详情和监控详情使用已有共享会话的通话状态，不新增连接或事件读取方。
- 双镜头详情的标记跟随当前主画面；单独全屏某个镜头时转到该镜头画面，退出后恢复。提示不截获鼠标或键盘。
- 同时录像时，在红色录制提示下方显示绿色通话提示，避免重叠。
- 结束通话、摄像头主动结束、麦克风停止、重连、退出、最小化和家庭切换继续沿用既有通话清理，标记随状态隐藏。其他摄像头不会被标为通话中。
- 原来的音量和静音图标保持不变。

按此前“不验证”的要求，仅生产编译、交付文件一致性核对及正常启动；不运行新增测试、浏览器检查或实机通话。以上显示、失败、释放、双镜头、全屏及与录制提示同时显示的场景均待验证，不记为通过。
