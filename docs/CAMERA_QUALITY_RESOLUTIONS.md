# 摄像头画质与码流去重

## 行为

- 详情、双镜头详情和监控墙使用同一套画质标签及尺寸记录。
- 画质菜单只显示型号支持的“超清、高清、流畅、自动”，不附带分辨率。实际解码尺寸仅用于内部识别重复手动档位。
- 最多保留 128 台设备的当前账号代次、家庭、型号、镜头和手动档位观测。标称尺寸、自动档和旧版磁盘读值不参与去重；不主动切换画质探测。
- 命令确认和视频边界分别处理。双镜头独立等待关键帧和稳定解码尺寸。切换前的帧及后台低码流不写入前台档位。
